# Datenschutzerklärung – Gefahrenmatrix

## Kurzfassung

Die App „Gefahrenmatrix“ erhebt, speichert und übermittelt **keine personenbezogenen Daten**. Alle Eingaben bleiben ausschließlich auf Ihrem Gerät.

## Welche Daten verarbeitet die App?

Eingaben in der App (Markierungen in der Matrix, Beschriftungen, Einsatzstichwort und Notizen) werden **lokal auf Ihrem Gerät** gespeichert, damit sie beim nächsten Öffnen der App wieder vorhanden sind. Diese Daten werden nicht an den Entwickler, an Server oder an Dritte übertragen.

Die App enthält:

- keine Nutzerkonten und keine Anmeldung,
- keine Werbung,
- keine Analyse- oder Tracking-Dienste,
- keine Drittanbieter-Software, die Daten erhebt,
- keine Verbindung zu einem Server des Entwicklers.

## PDF-Export

Die App kann aus Ihren Eingaben ein PDF erstellen. Das PDF wird auf Ihrem Gerät erzeugt. Es wird nur dann weitergegeben, wenn Sie es selbst über die Funktion „Teilen“ an eine andere App senden oder über „In Dateien sichern“ ablegen. Für die Weitergabe und Speicherung gelten dann die Datenschutzbestimmungen der von Ihnen gewählten App oder des gewählten Dienstes (z. B. Mail, AirDrop, iCloud Drive).

## Löschen Ihrer Daten

Sie können alle Eingaben in der App jederzeit mit dem Symbol „Zurücksetzen“ löschen. Durch das Löschen der App von Ihrem Gerät werden die gespeicherten Daten ebenfalls entfernt. Bereits erstellte und gesicherte PDF-Dateien müssen Sie gegebenenfalls selbst löschen.

## Kinder

Die App richtet sich nicht an Kinder und erhebt keine Daten von Kindern.

## Änderungen

Sollte sich die Funktionsweise der App ändern und Daten verarbeitet werden, wird diese Erklärung entsprechend angepasst.
